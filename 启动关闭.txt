rem 在本仓库根目录执行；两个窗口分别启动后端与前端
start "AI-LogInsight-backend" cmd /k "cd /d %~dp0backend && .venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload"
start "AI-LogInsight-frontend" cmd /k "cd /d %~dp0frontend && npm run dev -- --host 127.0.0.1 --strictPort"

关闭：Ctrl+C
